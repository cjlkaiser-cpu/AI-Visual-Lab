📚 Superposicion

Las redes neuronales pueden codificar mas features que neuronas usando superposicion: multiples features comparten las mismas dimensiones.

W^T W x reconstruye la entrada. Si M ≤ N, cada feature tiene su propia dimension (sin interferencia). Si M > N, features se superponen y compiten.

La sparsity es clave: cuanto mas dispersas son las features, mas caben sin interferencia. El diagrama de fase muestra la transicion entre representacion completa y superposicion.
