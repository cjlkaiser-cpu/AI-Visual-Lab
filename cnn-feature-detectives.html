¿Que es una CNN?

Una Red Neuronal Convolucional aplica filtros pequenos (3×3) que se deslizan sobre la imagen. Cada filtro detecta un patron especifico como bordes, esquinas o texturas.

Jerarquia de features

  • Capa 1: bordes simples (horizontal, vertical, diagonal)
  • Capa 2: combinaciones de bordes (esquinas, curvas)
  • FC: combinacion final para clasificar el digito

La operacion de convolucion

El filtro se multiplica elemento a elemento con cada region de la imagen y se suma el resultado: (f * g)(x,y) = ΣΣ f(i,j) · g(x-i,y-j)

Despues se aplica ReLU (max(0, x)) y opcionalmente Max Pooling para reducir el tamano.
