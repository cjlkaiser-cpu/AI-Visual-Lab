📚 Mixture of Experts

A Mixture of Experts layer routes each input to a subset of specialized expert networks. A learned gating router decides which experts process each input.

Router: g(x) = TopK(softmax(W_g * x / T))
Output: y = sum of g_i * E_i(x)

Top-1 sends each input to one expert (sparse). Top-2 blends two experts (denser). A load balance loss prevents all inputs from collapsing to a single expert.
