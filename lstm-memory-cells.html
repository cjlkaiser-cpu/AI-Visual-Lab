¿Que es una celula LSTM?

Una LSTM (Long Short-Term Memory) es un tipo de red recurrente que resuelve el problema de la memoria a largo plazo. Tiene tres compuertas que controlan el flujo de informacion:

  • Forget gate: que olvidar de la memoria
  • Input gate: que nueva informacion guardar
  • Output gate: que parte de la memoria usar

Cell state: el rio de la memoria

El cell state (Ct) fluye horizontalmente a traves del tiempo, como un rio. Las compuertas pueden borrar informacion (forget gate = 0) o anadir nueva (input gate = 1).

Formula: Ct = ft ⊙ Ct-1 + it ⊙ C̃t

¿Por que importan las LSTM?

Las RNN simples pierden informacion rapidamente (vanishing gradient). Las LSTM mantienen memoria durante cientos de pasos. Son fundamentales en:

  • Procesamiento de lenguaje natural
  • Prediccion de series temporales
  • Generacion de musica y texto
  • Traduccion automatica (antes de Transformers)
